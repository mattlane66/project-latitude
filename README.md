# Project Latitude V1.0

Slice S1: Manual Blueprint Canvas.

This repo is a small local Vite + React + TypeScript app for shaping product intent into editable, typed canvas cards. S1 is manual only: no AI calls, no API keys, no export packet, no auth, no multiplayer, no Miro integration, and no deployment automation.

## Local Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## S1 Demo Path

1. Open the app.
2. Enter a project title.
3. Type a product idea into the transcript input.
4. Add a manual card.
5. Select the card and edit type, title, body, and status in the inspector.
6. Drag the card to a new position.
7. Refresh and confirm the local session persists.

Planning source artifacts are copied into `docs/planning/`.
